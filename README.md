# 熟词僻义乐园 · 初一英语

面向初一学生的英语熟词僻义互动背诵网页，**单文件纯 HTML**，零依赖、零构建，双击即可运行。

数据来自《初一英语熟词僻义背诵表》，共 **46 个高频词、92 条释义**，每词均含「原义」与「僻义」两组对比。

## 在线访问

https://hellenyijun-hub.github.io/vocab-app/

## 六种玩法

| 玩法 | 说明 |
| --- | --- |
| 🃏 翻翻卡片 | 3D 翻卡。先看单词想两种意思，翻面看原义与僻义对照 + 例句 |
| 🎯 句子选义 | **给出例句**，选出该词在此句中的意思。四选一，例句中目标词高亮 |
| 🧩 配对消消乐 | 6 组英文与中文连线，点英文再点释义 |
| 📖 完整词表 | 92 条释义全文检索，可按单词 / 音标 / 释义 / 例句搜索，按类型筛选 |
| 📒 错题本 | 自动收录做错的词义，只练错题 |
| ✍️ 拼写填空 | 给中文释义和挖空例句，把单词拼出来，可逐字母提示 |

### 学习机制

- **掌握判定**：同一词义答对 **2 次**才算掌握（`mastery` 计数）
- **加权出题**：优先抽取未掌握的词义，已掌握的偶尔出现用于巩固
- **错题闭环**：答错自动进错题本并扣减熟练度，答对自动移出
- **星级激励**：答对得星，连对 3 题以上额外加成，星级总数显示在顶栏
- **等级称号**：🌱 单词小苗 → 🌿 词汇学徒 → 🌳 熟词达人 → 🏆 僻义大师

## 技术特点

- **单文件**：HTML + CSS + JS 全在一个 `index.html`，约 35 KB，无外部请求
- **零依赖**：不需要 npm install，不需要构建，改完直接刷新
- **音效**：Web Audio API 实时合成，无音频文件
- **朗读**：浏览器原生 `SpeechSynthesis`，英式发音
- **深色模式**：跟随系统 `prefers-color-scheme` 自动切换
- **响应式**：移动端优先，最大宽度 640px居中
- **进度存储**：`localStorage`，键名 `cz-vocab`

## 数据维护

全部词条在 `index.html` 的 `const DATA=[...]` 里，结构为：

```js
{
  "id": 1,
  "w": "absent",
  "ph": "/ˈæbsənt/",
  "o": { "m": "adj. 缺席的", "s": "He was absent from school because of illness." },
  "r": { "m": "adj. 心不在焉的", "s": "She had an absent look during the class." }
}
```

`o` = 原义（common），`r` = 僻义（rare）。增删单词只改这一处，所有玩法和检索自动生效。

**注意**：`hl()` 和 `tok()` 函数靠单词在例句中的出现来定位，需要保证新加的例句里包含该单词。

## 部署

GitHub Pages，源码与产物是同一个 `index.html`（无构建步骤）。

```bash
# 注意：本机代理若不可用，git 命令需绕过代理
env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY bash deploy-push.sh
```

`main` 分支存源码，`gh-pages` 分支存站点文件。
